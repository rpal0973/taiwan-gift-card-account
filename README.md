## 台区卡为什么充不进国区账号

这不是平台设置的门槛，是苹果自己的发行规则。台区充值卡的说明写得很直接：「本充值卡仅限中国台湾本地注册的苹果ID使用，不支持其他地区apple ID使用。」同一份说明还举了个例子：在台湾买的礼品卡，无法在香港的 iTunes Store 兑换。

礼品卡按区域发行，余额只能进对应区域的 Apple 账户。你拿国区 ID 去兑美区卡，兑换会直接失败；拿美区 ID 去兑台区卡，结果一样。所以第一步不是找卡，是确认你手里要充值的账号到底是哪个区。

**怎么查**：iPhone 打开「设置」，点最上方的 Apple ID 头像，进「媒体与购买项目」，里面显示的账户国家/地区就是你这个 ID 的所属区。国区就是中国大陆，别拿它去兑任何外区卡。

**兑换流程**（台区卡、美区卡通用，只是登录的 ID 不同）：

1. iPhone 或 iPad 打开 App Store，点右上角头像
2. 找到「兑换代码或礼品卡」，选「手动输入代码」
3. 输入 16 位、以 X 开头的兑换码
4. 确认兑换，余额自动更新到账户

旧版 iOS 的入口位置不一样：打开 iTunes Store App，滑到「精选」板块底部，点「兑换」，登录 Apple ID 后同样选手动输入。Mac 上则是在 iTunes 里登录后，点自己的名字，从菜单里选「兑换」。找不到入口时先看系统版本，别反复重装 App。
